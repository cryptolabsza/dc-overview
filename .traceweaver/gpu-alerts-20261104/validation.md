# Validation definition

Operator question: Can a recipient identify a GPU fault versus a broken collector, see its action/count and recognize true recovery within a short message?

Local acceptance: real incident metrics trigger one host collector instance; two independent positive controls retain inventory/hardware faults; current complete counts restore, missing/stale series and monitoring changes do not claim recovery. Actual Go-template rendering checks concise firing/restored/monitoring-changed output. Watchdog per-channel queue preserves detailed diagnostics and exact payload hashing.

Reviewer: independent native review, no production mutations. Deployment acceptance: official immutable source/image, intended site only, backups and preserved other-role settings, fresh Prometheus metrics and actual Grafana evaluation cycles after reload. Live delivery/history remains unproven until audited. No new Telegram TEST sends under this package.
